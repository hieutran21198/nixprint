# Agent Phase Handoff Assignment

## Scope

This scope enforces the delivery handoff from a requirement ticket to a
specification ticket, then to a task-plan ticket, and then to implementation.

## Scope-Level Owner

The Delivery Workflow service maintainer owns this scope.

## Included Concerns

- Root requirement-ticket assignment.
- Predecessor-linked documentation handoffs.
- Builder assignment reuse at implementation start.
- Agent guidance for each assignment decision.

## Excluded Concerns

- Documentation artifact ownership and acceptance authority.
- GitHub Project configuration and token provisioning.
- Post-implementation ticket completion.
