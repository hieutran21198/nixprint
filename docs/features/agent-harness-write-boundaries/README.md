# Agent Harness Write Boundaries

## Scope

This feature defines enforced write boundaries for Polyrepo implementation
experts. It generates compatible client guardrails for Codex, Claude Code, and
OpenCode.

## Scope-Level Owner

The agent service maintainer owns this scope. The implementation belongs to
the `services` repository category.
