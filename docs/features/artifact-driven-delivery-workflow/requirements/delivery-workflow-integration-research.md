# Delivery Workflow Integration Research Requirement

## Outcome

Provide focused, provider-independent research that explains how the four
Artifact-Driven Development phases integrate with Git hosting, CI/CD, and
execution systems.

## Constraints

- Preserve the specified ticket-state semantics without requiring provider
  state names.
- Use official provider documentation where possible.
- Keep the research focused on the core workflow.

## Acceptance Criteria

- The research covers GitHub, GitLab, Bitbucket Cloud, Jira, Linear, and
  GitHub Projects.
- The research defines the responsibility boundary for version control, CI/CD,
  the execution system, and the integration layer.
- The research provides a provider-independent correlation and transition
  model.
- The research identifies the changes required for reliable terminal ticket
  transitions.
