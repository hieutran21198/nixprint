# GitHub Delivery Workflow Starter

## Scope

This feature implements the first delivery-workflow adapter. It uses GitHub,
GitHub Actions, GitHub Issues, GitHub Projects, and the `dw` Go tool.

## Scope-Level Owner

The delivery-workflow service maintainer owns this scope.
